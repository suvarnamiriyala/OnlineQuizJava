# Online Quiz System (Java)

## Description
A console-based Online Quiz Application developed using Java.
The system allows users to answer multiple-choice questions and view their final score.

## Features
- Multiple-choice questions
- Instant answer validation
- Score calculation
- Object-Oriented Programming
- Simple and clean code

## Technologies Used
- Java
- OOP Concepts
- Collections (ArrayList)

## How to Run
1. Compile all Java files in the `src` folder.
2. Run the `Main` class from the command line or your IDE.
